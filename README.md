# 1. 🚕 Uber_SQL_Analysis (Using MS SQL Server)

## 2. Project Overview
This project involves a comprehensive analysis of **Uber** trip data using **SQL** to gain insights into booking trends, revenue, and trip efficiency, helping stakeholders make data-driven decisions.

## 3. Key Insights & Features

* **KPI Trackings:** Monitoring essential metrices including.  
   **1. Total Bookings(1,03,728)**  
   **2. Total Booking Values(Rs. 1.34M)**  
   **3. Average Booking Values(Rs. 12.99)**  
   **4. Total Trip Distance(348K km)**  
   **5. Average Trip Distance(3.36 km)** 
   **6. Average Trip Duration(15 Minutes)**
